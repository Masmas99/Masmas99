### `02 / NETWORK MONITOR`

**MikroTik Network Monitoring**

A network monitoring concept focused on visualizing infrastructure and connection status.

```text
                    INTERNET
                       │
                       ▼
                ┌─────────────┐
                │   MIKROTIK  │
                └──────┬──────┘
                       │
            ┌──────────┼──────────┐
            │          │          │
            ▼          ▼          ▼
          ROUTER     SWITCH      AP
            │          │          │
            └──────────┼──────────┘
                       │
                    CLIENTS
```

Planned monitoring:

* Router status
* Interface traffic
* Device availability
* Network topology
* Connection health
* Real-time status
* Interactive map visualization

**Stack**

`Laravel` `Vue.js` `MikroTik API` `MySQL`
